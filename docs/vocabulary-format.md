# Vocabulary Format

Each entry starts with a level-2 heading:

```md
## word /phonetic/
```

Supported fields:

```md
- 释义：Chinese meaning
- 助记：mnemonic
- 助读：reading help
- 来源：source
```

English labels are also accepted:

```md
- Meaning: ...
- Mnemonic: ...
- Reading: ...
- Source: ...
```

Only the word heading is required. Meanings and readings improve the generated review notes.
